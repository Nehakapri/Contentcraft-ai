About ContentCraft AI

ContentCraft AI is a college software-engineering project. It lets a user generate, summarize, rewrite and polish text with an AI model, and keep the results they like in a local history. It is meant for students, teachers, content creators and professionals.

Technologies used

  • Frontend: HTML5, CSS3 and vanilla JavaScript (Fetch API for server calls).
  • Backend: Python 3 and Flask, exposing a small REST API.
  • Database: SQLite, accessed through Python's built-in sqlite3 module.
  • AI: Google Gemini API through the official google-genai SDK.
  • Configuration: a .env file loaded with python-dotenv.

How the pieces fit together

  1. The browser shows the pages and sends the user's request as JSON to Flask.
  2. Flask validates the request, builds a prompt from a template, and asks the AI service to generate text.
  3. The AI service calls the Gemini API. The API key stays on the server and never reaches the browser.
  4. The generated text goes back to the browser as JSON. If the user saves it, Flask stores it in SQLite.
  5. The History page reads saved items back from SQLite.

Good to know

  • This version is single-user and local. There are no accounts or login, so anyone who can open the site on this computer can see the saved history. A multi-user version would need authentication and authorization.
  • AI providers can change free-tier limits, models and pricing at any time, and may apply quotas.
  • AI-generated text can be wrong. Review it before you use it.
